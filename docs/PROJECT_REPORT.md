# Student Management & Analytics System

## Objective
Create a relational database that stores and analyzes college student information while demonstrating practical SQL development skills.

## Core modules
1. Student management
2. Department management
3. Teacher/course management
4. Enrollment tracking
5. Marks management
6. Attendance tracking
7. Fee tracking
8. Analytics/reporting

## SQL concepts demonstrated
- DDL and DML
- Constraints
- Primary and foreign keys
- UNIQUE constraints
- INNER and LEFT JOIN
- GROUP BY and HAVING
- Aggregate functions
- Subqueries
- CTE
- Views
- Indexes
- EXPLAIN
- Data validation
- Duplicate detection

## Expected outcome
The project demonstrates the ability to design a relational schema, write useful business queries, validate data and apply basic query optimization.
