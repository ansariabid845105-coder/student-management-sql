# Student Management & Analytics System

A beginner-friendly MySQL project designed for an SQL Developer Internship portfolio.

## Tech
- MySQL 8+
- SQL
- Git/GitHub

## Features
- Normalized relational database
- Students, departments, courses, teachers, enrollments, marks, attendance and fees
- Primary/foreign keys and constraints
- JOINs, subqueries, CTEs and aggregations
- Views for reporting
- Duplicate-data detection
- Indexes and query optimization examples
- Data validation queries

## How to run

1. Install MySQL 8+ and MySQL Workbench.
2. Open `sql/01_schema_and_data.sql`.
3. Run the complete file.
4. Open `sql/02_business_queries.sql` and run individual queries.
5. Open `sql/03_optimization.sql` to see indexes and `EXPLAIN`.
6. Open `sql/04_validation_and_deduplication.sql` for data-quality checks.
7. Open `sql/05_views.sql` to create reporting views.

## Suggested interview explanation

"I designed a normalized MySQL database for college student management. I used foreign keys to maintain referential integrity, joins and aggregations for reports, views for reusable reporting, and indexes with EXPLAIN to improve query performance. I also included data-validation and duplicate-detection queries."

## Portfolio note

This project is intentionally SQL-focused because the target internship emphasizes SQL, relational databases, data validation/deduplication, migrations, query writing and optimization.
